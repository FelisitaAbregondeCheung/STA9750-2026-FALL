Mini-Project 01 - What We Watched

Exploring Netflix Viewing Data

Author

Felisita Abregonde Cheung

Executive Summary

Netflix has about 325 million subscribers worldwide, and only roughly a quarter are in the United States and Canada — a reminder that the company’s audience is now overwhelmingly international. That global reach is reflected in what people watch. In my analysis, titles available worldwide represented just 35.09% of the catalog but generated 51.92% of viewing hours, while Netflix reports that non-English programming now accounts for more than a third of all viewing.

Yet American series remain a powerful part of Netflix’s global appeal. Series accounted for roughly 95% of viewing time from 2023H2 onward in this study, with franchises such as Bridgerton and Stranger Things drawing billions of viewing hours across the study period. The franchise effect can be substantial: Netflix reported that the arrival of Bridgerton Season 4 nearly tripled viewing of its earlier seasons in the first half of 2026.

Netflix is also widening the definition of what belongs on a streaming service. Live programming in the data expanded from just 3 events in 2024H2 to 117 in 2026H1, although it still represented only 0.46% of viewing in the latest period. Netflix’s own 2026 report highlights live comedy, a live climbing event and BTS’s global comeback alongside its traditional movies and series.

Furthermore, the Gini analysis shows that viewing remains concentrated among a relatively small share of Netflix titles, even though no single hit dominates the platform. For Netflix, whose customers live beyond the US/Canada market, the challenge is to keep producing American franchises that could potentially be a global hit and finding media gems in other parts of the world, while increasing the full potential of ‘live events’ that give viewers reasons to keep watching.

Task 1: Data Acquisition

Netflix publishes its What We Watched engagement reports every six months. For this analysis, I use the seven available reports from 2023H1 through 2026H1 and combine them into a single dataset.

library(tidyverse)

load_netflix_data <- function(){

  data_dir <- path("data", "mp01")

  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings = FALSE, recurse = TRUE)
  }

  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )

  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }

    return(local)
  }

  NETFLIX_URLS |>
    map(read_html) |>
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |>
    map_chr(html_attr, "href") |>
    enframe("period", "url") |>
    mutate(
      path = path(data_dir, paste0(period, ".xlsx")),
      path = map2(url, path, download_if_needed),
      data = map(path, read_excel, skip = 3, na = "*"),
      data = map(data, \(x) x |>
        mutate(`Release Date` = as.Date(`Release Date`)))
    ) |>
    unnest(data) |>
    select(-url, -path) |>
    mutate(
      year = str_sub(period, 1, 4),
      half = str_sub(period, start = 6),
      period_start = make_date(
        year,
        if_else(half == 1, 1, 7),
        1
      ),
      period_end = make_date(
        year,
        if_else(half == 1, 7, 12),
        if_else(half == 1, 30, 31)
      )
    ) |>
    filter(!is.na(`Hours Viewed`)) |>
    mutate(
      live_event = !is.na(Runtime) &
        str_detect(Runtime, "\\d+:\\d+\\*"),
      clean_time = str_remove(Runtime, fixed("*")),
      Runtime = 60 * hour(hm(clean_time)) +
        minute(hm(clean_time))
    ) |>
    select(-clean_time) |>
    mutate(
      Runtime = coalesce(Runtime, mean(Runtime, na.rm = TRUE)),
      .by = Title,
      Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
      Title = str_remove(Title, " // .*"),
      Title = str_remove(Title, "[^[:ascii:]].*"),
      Title = str_trim(Title)
    ) |>
    filter(Title != "") |>
    select(
      year,
      period,
      period_start,
      period_end,
      Title,
      -half,
      Runtime,
      Views,
      `Hours Viewed`,
      `Release Date`,
      `Available Globally?`,
      live_event
    ) |>

    # Task 2: standardizing column names
    rename(
      title = Title,
      runtime = Runtime,
      views = Views,
      hours_viewed = `Hours Viewed`,
      release_date = `Release Date`,
      available_globally = `Available Globally?`
    )
}

Question 3: Consistently Popular Titles

I developed a Consistency Score to identify titles with steady viewing worldwide and across all seven periods. Superstore, Neon Genesis Evangelion, BoJack Horseman, and Brooklyn Nine-Nine stand out for sustained, stable viewership. SURPRISINGLY, three of these top series are made in the United States, considering there are about 325 million Netflix subscribers and about 89 million subscribers are in the US ( Statista, January 13, 2026)

Show consistently popular titles analysis 
consistent_titles <- NETFLIX_DATA |>
  group_by(title) |>
  summarise(
    periods_present = n_distinct(period),
    average_hours = mean(hours_viewed, na.rm = TRUE),
    minimum_hours = min(hours_viewed, na.rm = TRUE),
    sd_hours = sd(hours_viewed, na.rm = TRUE)
  ) |>
  filter(periods_present == 7) |>
  mutate(
    average_rank = percent_rank(average_hours),
    minimum_rank = percent_rank(minimum_hours),
    stability_rank = 1 - percent_rank(sd_hours),
    consistency_score = (
      average_rank +
      minimum_rank +
      stability_rank
    ) / 3
  ) |>
  arrange(desc(consistency_score)) |>
  slice_head(n = 10)

Question 4: Shows vs. Movies

Shows or series are popular on Netflix worldwide. From 2023H2 onward, shows consistently accounted for about 95% of viewing time, while movies represented only about 4–5%.

A four-hour runtime threshold is used as one indicator for identifying ‘series’ shows. Titles containing the word “Season” are also classified as shows.

Show shows vs. movies analysis 
shows_vs_movies <- NETFLIX_DATA |>
  mutate(
    content_type = case_when(
      str_detect(
        title,
        regex("Season", ignore_case = TRUE)
      ) ~ "Show",
      runtime >= 240 ~ "Show",
      TRUE ~ "Movie"
    )
  ) |>
  group_by(period, content_type) |>
  summarise(
    hours_viewed = sum(hours_viewed, na.rm = TRUE),
    .groups = "drop"
  ) |>
  group_by(period) |>
  mutate(
    viewing_share = hours_viewed / sum(hours_viewed)

  ungroup()

NoteBig Hits and the Long Tail

Live programming is still a small piece of Netflix, but it is growing fast. Live events rose from just 3 in 2024H2 to 117 in 2026H1, generating 343.2 million viewing hours, or 0.46% of total viewing. For Netflix, the path forward is global but diversified. The company should build franchises that travel across borders, invest in regional stories with international appeal and protect the broad catalog that keeps viewers watching between major hits. Live programming can grow alongside that business — but as a complement, not a replacement, for the on-demand content at Netflix’s core.

Extra Credit: Gini Analysis

Measuring the Concentration of Netflix Viewing

Netflix viewing is far from evenly spread across its catalog. A Gini of 0 means viewing is shared evenly among titles; a Gini of 1 means most viewing goes to only a few. Netflix’s score hovered around 0.75 from 2024 through 2026, pointing to a persistent concentration of viewing among a relatively small group of titles. The gap between the 0.708 Gini for runtime-adjusted views and 0.755 for viewing hours in 2026H1 also suggests that longer titles account for some — but not all — of that concentration.

gini_coefficient <- function(x) {
  x <- x[!is.na(x)]
  x <- sort(x)
  n <- length(x)

  (2 / n) *
    (sum(seq_len(n) * x) / sum(x)) -
    ((n + 1) / n)
}
